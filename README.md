## Projetos acadêmicos

### Engenharia de Prompt aplicada à segurança de senhas

Análise dos riscos do uso de MD5 na proteção de senhas e desenvolvimento de um prompt seguro e verificável. O projeto utilizou conceitos relacionados a Python 3.12, Argon2id, argon2-cffi e boas práticas da OWASP e do NIST.

O trabalho também considerou revisão humana, critérios de aceitação e validação das respostas produzidas pela inteligência artificial.

### Sistema de Controle de Estoque em Python

Sistema desenvolvido em Python com menu interativo, dicionários aninhados, estruturas condicionais, laços de repetição e regras para entrada e saída de produtos.

O projeto verifica a existência do produto e a disponibilidade de estoque antes de realizar uma retirada.

### Conversor de temperatura e calculadora de fatorial

Scripts desenvolvidos em Python para conversão de temperaturas e cálculo de números fatoriais. Foram utilizados tipos de dados, conversão de valores, f-strings, formatação de casas decimais e a biblioteca math.
